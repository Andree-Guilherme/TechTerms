# Termos de Banco de Dados e Programação 💻📚

Este repositório serve como **guia rápido de termos** usados em banco de dados, SQL, programação, blockchain, licenças e também gírias de desenvolvedor. Ideal para iniciantes e profissionais que buscam referência rápida.

---

## 📊 Termos de Banco de Dados e SQL

| Termo | Descrição |
|-------|-----------|
| **Índice (Index)** | Recurso do SQL Server para ordenar dados em uma sequência específica, permitindo retorno mais eficiente. |
| **SGBD / DBMS** | Sistema Gerenciador de Banco de Dados, usado para gerenciar, acessar, organizar e proteger informações. |
| **Query** | Solicitação de informações a um banco de dados. |
| **Constraints** | Regras de integridade e consistência aplicadas às colunas das tabelas. |
| **Result Set** | Saída de uma consulta no banco de dados, de uma linha até milhões de registros. |
| **Dump** | Backup de um banco de dados. |
| **Wildcard (Carta coringa)** | Usado com `LIKE` para filtrar dados por padrões em SQL. |
| **Cláusulas** | Partes de uma instrução SQL com funções específicas, como `SELECT`, `WHERE`, `GROUP BY`. |

## 💻 Programação e Desenvolvimento

| Termo | Descrição |
|-------|-----------|
| **Mock** | Objeto simulado para testar código de forma isolada. |
| **Parsear** | Converter dados de um formato para outro. |
| **Casting** | Conversão de um tipo de dado para outro compatível. |
| **Statement** | Instrução ou comando que indica o que o código deve executar. |
| **Emmet** | Plugin/ferramenta para escrever HTML e CSS mais rápido. |
| **Issue** | Ferramenta para registrar e acompanhar problemas ou tarefas de um projeto. |
| **Fork** | Criação de uma cópia independente de um repositório existente. |

## ⛓ Blockchain e Licenças

| Termo | Descrição |
|-------|-----------|
| **Fork** | Modificação do código-fonte de um projeto de blockchain. |
| **Blockchain** | Tecnologia de registro distribuído que busca descentralização e segurança. |
| **GPL (General Public License)** | Licença de software livre que permite executar, estudar, modificar e distribuir o software. |
