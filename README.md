# Guia de Termos de Tecnologia 💻📚

Este repositório serve como um **guia rápido de termos e gírias** usados em programação, banco de dados, infraestrutura e outras áreas da tecnologia. Ideal para iniciantes e profissionais que buscam uma referência prática.

---

## 💻 Programação

### Termos Técnicos

| Termo | Descrição |
|-------|-----------|
| **API** | **Application Programming Interface:** Conjunto de regras e ferramentas para construir softwares e aplicações, permitindo que diferentes sistemas se comuniquem. |
| **Mock** | Objeto simulado usado para testar um trecho de código de forma isolada, sem depender de suas partes reais. |
| **Parsear** | Analisar e converter dados de um formato para outro (ex: de texto para um objeto). |
| **Casting** | Converter um tipo de dado para outro compatível (ex: de `int` para `string`). |
| **Statement** | Instrução ou comando que indica ao programa a ação que ele deve executar. |
| **Framework** | Estrutura de código pré-escrita que serve de base para o desenvolvimento de aplicações, definindo como o desenvolvedor deve trabalhar. |
| **Biblioteca (Library)** | Coleção de códigos prontos para realizar tarefas específicas, que pode ser reutilizada em diferentes projetos. |
| **Refatorar** | Reestruturar um código existente para melhorar sua clareza, eficiência ou manutenção, sem alterar seu comportamento externo. |
| **Merge** | Processo de combinar diferentes versões de um código (branches) em um único arquivo ou branch. |
| **Issue** | Ferramenta para registrar e acompanhar problemas, tarefas ou melhorias em um projeto (comum em plataformas como GitHub). |
| **Fork** | Cópia independente de um repositório, permitindo que alguém trabalhe em um projeto sem alterar o original. |
| **Emmet** | Ferramenta que acelera a escrita de HTML e CSS através de abreviações. |

### Gírias e Expressões

| Gíria | Significado |
|-------|------------|
| **Gambiarra** | Solução improvisada, rápida e geralmente de baixa qualidade, mas que resolve o problema temporariamente. |
| **Bugar / Bugou** | Gíria para quando um código ou sistema apresenta um comportamento inesperado ou para de funcionar. |
| **Debugar** | O ato de procurar e corrigir "bugs" (erros) em um código. |
| **Comitar** | Salvar e registrar as alterações feitas no código em um sistema de controle de versão, como o Git. |
| **Buildar** | Processo de compilar o código-fonte e empacotar os arquivos para gerar uma versão executável de um software. |
| **Deployar** | Publicar uma nova versão de um software em um ambiente (de teste ou produção) para que os usuários possam acessá-la. |
| **Código Espaguete** | Código mal estruturado, confuso e difícil de entender, onde a lógica se entrelaça como um prato de espaguete. |
| **Código Legado** | Código antigo, muitas vezes herdado de outros desenvolvedores, que ainda está em produção mas é difícil de manter. |
| **Mó licença de winrar** | Algo que é inútil ou que ninguém se importa. |
| **Me deu um 404** | Gíria para quando alguém não aparece a um compromisso ("dar bolo") ou quando algo falha. |
| **Quase que fui de drop table** | Expressão para um susto ou situação de quase desastre, fazendo alusão ao comando SQL que apaga uma tabela inteira. |
| **Tô muito PHP** | Cansado, sobrecarregado ou com "dor de cabeça", em referência à fama da linguagem de ser complexa em alguns cenários. |

## 📊 Banco de Dados

| Termo | Descrição |
|-------|-----------|
| **SGBD / DBMS** | **Sistema Gerenciador de Banco de Dados:** Software para gerenciar, acessar e proteger dados (ex: MySQL, PostgreSQL, SQL Server). |
| **Query** | Uma solicitação de informações a um banco de dados, geralmente escrita em uma linguagem como SQL. |
| **Result Set** | O conjunto de dados retornado por uma consulta (query) ao banco de dados. |
| **Índice (Index)** | Estrutura de dados que melhora a velocidade de busca e recuperação de informações em uma tabela. |
| **Constraints** | Regras aplicadas às colunas de uma tabela para garantir a integridade e a consistência dos dados. |
| **Cláusulas** | Comandos específicos de uma instrução SQL, como `SELECT`, `WHERE`, `GROUP BY`, que definem a operação a ser realizada. |
| **Join** | Operação em SQL usada para combinar registros de duas ou mais tabelas com base em uma coluna relacionada. |
| **Stored Procedure** | Bloco de código SQL pré-compilado e armazenado no banco de dados, que pode ser executado repetidamente. |
| **Trigger** | Procedimento especial que é executado automaticamente em resposta a um evento no banco de dados (como `INSERT`, `UPDATE` ou `DELETE`). |
| **ETL** | **Extract, Transform, Load:** Processo de extrair dados de uma fonte, transformá-los em um formato adequado e carregá-los em um destino (como um Data Warehouse). |
| **NoSQL** | Tipo de banco de dados não relacional, que armazena dados em formatos flexíveis como documentos, grafos ou chave-valor (ex: MongoDB, Redis). |
| **ACID** | **Atomicidade, Consistência, Isolamento e Durabilidade:** Propriedades que garantem a confiabilidade das transações em um banco de dados. |
| **Dump** | Cópia de segurança (backup) de um banco de dados, geralmente em formato de script SQL. |
| **Wildcard** | Caractere coringa (como `%` ou `_`) usado com o operador `LIKE` em SQL para filtrar dados por padrões. |

## 🌐 Outros Termos

### Infraestrutura e DevOps

| Termo | Descrição |
|-------|-----------|
| **On-premise** | Infraestrutura de TI (servidores, armazenamento) instalada e operada localmente, dentro das instalações da própria empresa. |
| **Cloud Computing** | Fornecimento de serviços de computação (servidores, armazenamento, software) pela internet ("a nuvem"), sob demanda. |
| **DevOps** | Cultura e conjunto de práticas que unem o desenvolvimento de software (Dev) e as operações de TI (Ops) para acelerar a entrega de software. |
| **CI/CD** | **Continuous Integration/Continuous Deployment:** Automação dos processos de integração e entrega de código, permitindo lançamentos mais rápidos e seguros. |
| **Container** | Pacote de software que inclui o código e todas as suas dependências, garantindo que a aplicação rode de forma consistente em qualquer ambiente. |
| **VM (Virtual Machine)** | Emulação de um sistema de computador completo, que permite executar um sistema operacional "dentro" de outro. |

### Arquivos e Caminhos

| Termo | Descrição |
|-------|-----------|
| **File path** | Caminho que leva a um arquivo em um sistema de arquivos. |
| **Directory path** | Caminho que leva a uma pasta (diretório). |
| **Absolute path** | Caminho completo a partir da raiz do sistema (ex: `C:\Users\...\file.txt`). |
| **Relative path** | Caminho a partir do diretório atual (ex: `.\data\file.txt`). |
| **.csv** | **Comma-Separated Values:** Arquivo de texto onde os valores são separados por vírgula, usado para dados tabulares. |
| **.json** | **JavaScript Object Notation:** Formato de texto leve para intercâmbio de dados, muito usado em APIs web. |
| **.xml** | **Extensible Markup Language:** Linguagem de marcação para armazenar e transportar dados de forma estruturada. |
| **.bson** | **Binary JSON:** Representação binária de documentos JSON, usada pelo MongoDB para armazenar dados de forma eficiente. |

### Blockchain e Licenças

| Termo | Descrição |
|-------|-----------|
| **Blockchain** | Tecnologia de registro distribuído e imutável que busca garantir segurança e descentralização em transações digitais. |
| **Fork (Blockchain)** | Uma bifurcação no código-fonte de um projeto de blockchain, criando duas versões distintas da moeda ou plataforma. |
| **GPL** | **General Public License:** Licença de software livre que garante aos usuários a liberdade de executar, estudar, modificar e distribuir o software. |
